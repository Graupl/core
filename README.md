# Graupl Core

Graupl Core provides the styles, utilities, and JavaScript components for [Graupl](https://github.com/Graupl/graupl). It is part of [Accessible Ecosystem](https://github.com/Accessible-Ecosystem).

Install the beta with `npm install @graupl/core@beta`. Import individual components, such as `@graupl/core/accordion`, or use the bundled browser script at `dist/js/graupl.js`.

To compile the styles, enable Sass's Node package importer and use `@use "pkg:@graupl/core";`. Compiled CSS is available at `dist/css/graupl.css`.

See the [contribution guidelines](.github/CONTRIBUTING.md) for build and test instructions.
